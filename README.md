# 🐱🐶 Cats & Dogs Image Classifier

An interactive web application powered by Deep Learning (CNN) to classify images of cats and dogs, built using **Streamlit** and **TensorFlow**.

---

## 🔗 Notebook Reference
The complete model training, Exploratory Data Analysis (EDA), and data preprocessing pipeline can be found in the Kaggle Notebook:
