I just deployed a new Deep Learning project: Cats & Dogs Image Classifier! 🐱🐶

This end-to-end Computer Vision web application classifies images in real-time using a Convolutional Neural Network (CNN) built with TensorFlow and deployed via Streamlit.

Key Features:
* Custom CNN Architecture: Optimized for binary image classification.
* Modern UI: Clean, responsive user experience with real-time probability scores.
* Cloud Deployment: Hosted on Streamlit Community Cloud with cached model inference.
